# Atom Clones

**Live app:** https://atomclones.vercel.app

Atom Clones is a voice-cloning conversational app in the Atom suite — it clones your own voice and talks back to you in it. You speak, it listens via the Web Speech API, sends your words to Gemini for a reply, then synthesizes that reply in your cloned voice and plays it back, all in a turn-based conversational loop with a reactive orb interface.
